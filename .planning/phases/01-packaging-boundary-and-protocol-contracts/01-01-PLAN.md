<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| consumer import → package export map | Untrusted consumer specifiers select the published runtime/type target. |
| callback/runtime failure → public error | Arbitrary thrown values and potentially sensitive operation data cross into an observable SDK error. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | package.json exports | high | mitigate | Map exact and wildcard specifiers only to emitted `lib/hashtree` targets and prove each target after `pnpm build`. |
| T-01-02 | Information Disclosure | src/hashtree/errors.ts | high | mitigate | Copy only explicit operation/path/numeric fields and standard cause; tests reject arbitrary context retention and custom serialization. |
| T-01-03 | Denial of Service | src/hashtree/types.ts declarations | medium | mitigate | Restrict public contracts to Web/ES types and audit emitted declarations for Node-only coupling that would force browser polyfills. |
| T-01-04 | Spoofing | error discrimination | low | accept | `instanceof` and class name are documented local-realm discriminators; cross-realm identity is outside this phase's stated contract. |
</threat_model>
