<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| emitted root → transitive module graph | Static specifiers control which implementation and bare dependencies a root consumer receives. |
| repository → npm tarball → extracted consumer context | Pack metadata and archive contents cross from build workspace into the publishable artifact under test. |
| test process → temporary filesystem/subprocess | Generated paths and subprocess output are handled by the verification harness. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-05 | Tampering | emitted graph walker | high | mitigate | Resolve relative edges explicitly, fail on missing targets, track visited paths, and assert no path escapes into `lib/hashtree`. |
| T-01-06 | Information Disclosure | root package entry | high | mitigate | Independently assert namespace, fresh-process evaluation, and transitive bare/path graph isolation per D-14. |
| T-01-07 | Tampering | packed tarball selection | medium | mitigate | Parse `npm pack --json`, require exactly one declared tarball, extract into a unique temp directory, and assert exact export targets. |
| T-01-08 | Denial of Service | temporary package test resources | medium | mitigate | Bound work to one local tarball and remove the unique temporary directory in `finally` on every outcome. |
| T-01-09 | Elevation of Privilege | system tar subprocess | low | accept | The archive is generated locally from the repository and extracted into a unique test-owned temporary directory; no untrusted remote archive is accepted. |
</threat_model>
